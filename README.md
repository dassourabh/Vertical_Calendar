# Vertical Calendar

An Android calendar app built with **Kotlin**, designed for convenient date navigation, regional calendar viewing, and event tracking.

## Features

### 📅 Vertical Calendar Navigation
- Scroll vertically through the calendar.
- Navigate backward to previous dates and forward to upcoming dates.

### 🌏 Regional Calendars
- View regional calendar dates.
- Bengali and Telugu calendars are currently supported.
- Additional regional calendars may be added in future versions.

### 🔄 Google Calendar Synchronization
- Add events and synchronize them with your Google Calendar account.
- **Requirements:** Sign in with a Google account and grant the app the required calendar access permission.
- Synchronization depends on the account and permissions configured on the device.

### ⏳ Countdown Events
- Add countdown events for important upcoming dates and occasions.
- Keep track of how long remains until an event.

### 📱 Home Screen Widget
- Add a widget to your Android home screen.
- See the current date and day without opening the app.

## Getting Started (Developers)

1. Clone the repository:

   ```bash
   git clone https://github.com/dassourabh/Vertical_Calendar.git
   ```

2. Open the project in Android Studio.
3. Allow Gradle sync to finish and install any required SDK components.
4. Connect an Android device or start an emulator.
5. Build and run the app.
